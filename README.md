FleetPilot 
FleetPilot is a end to end web application, built for large fleet owners, to efficiently manage their large fleet (bus, trucks and cars).

Tech Stack : 
1. Frontend : HTML, CSS & JavaScript
2. Backend : Node.js and Express
3. Database : PostgreSQL

Status :
Under Development. Target MVP : 5 November 2026

Local Setup : 
Prerequisites: Node 24 LTS, PostgreSQL 18.
    1. Copy .env.example to .env and fill in values.
